
# ✅ To-Do App

A simple and clean To-Do application built with HTML, CSS, and JavaScript.

## 🔗 Live Demo
[Click here to view the app](https://farhan-gujjar.github.io/to-do-app/)

## 📋 Features
- Add new tasks
- Mark tasks as Done / Undone
- Edit existing tasks
- Delete tasks
- Live count of Total, Done, and Pending tasks

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript (Vanilla)

## 📁 How to Run
1. Clone or download this repository
2. Open `index.html` in any browser
3. Start adding your tasks!
